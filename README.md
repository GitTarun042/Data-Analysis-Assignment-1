# Student Performance Analysis

## Problem Statement

Educational institutions need to understand the factors that influence student academic performance. This project analyzes student data to identify performance trends and examine the relationship between study habits and final grades.

## Objectives

* Clean and validate the dataset.
* Analyze student final grades.
* Identify high-performing students.
* Examine the relationship between study time and academic performance.
* Compare performance across student groups.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

* Missing value check
* Duplicate removal
* Data type validation
* Average final grade calculation
* Students scoring above 15 marks
* Study time vs final grade correlation
* Visual analysis of student performance

## Key Insights

* Average student performance was calculated using final grades.
* High-performing students were identified for further analysis.
* Study time showed a measurable relationship with academic performance.
* Data visualizations helped uncover performance patterns.
